# Lab 03 – Performance Limits and Profiling

This lab contains results collected while running performance benchmarks and profiling tools.

## Files
- `graph1.pdf` – Roofline graph generated with the Empirical Roofline Toolkit (ERT).
- `callgrind.out.431` – Callgrind profiling output from CloverLeaf.
- `likwid_result.txt` – LIKWID performance counter output for CloverLeaf.
- `stream_result.txt` – STREAM benchmark output, including bandwidth results and validation.
- `hwloc_topology.txt` – Hardware topology reported by hwloc.
